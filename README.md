# VentaExpress: E-Commerce Quarterly Sales & Operations Analysis

## Project Overview
As a Data Analyst supporting the Chief Operating Officer (COO) at **VentaExpress** (a growing e-commerce company), I conducted an end-to-end audit, cleaning, and executive analysis of raw quarterly sales data using **Google Sheets / Excel**. The objective was to transform unprocessed operational records into reliable KPIs and strategic visualizations to guide executive decision-making.

## Key Methodology & Execution
* **Data Auditing & Systematic Cleaning:** Identified and documented anomalies in raw e-commerce transaction logs (duplicate entries, missing fields, inconsistent date/currency formats) and applied justified cleaning workflows.
* **Data Architecture & Standardization:** Restructured raw tables following professional spreadsheet modeling best practices to ensure data integrity and scalability.
* **KPI Calculation & Aggregation:** Computed core commercial and operational metrics (revenue trends, order volume, product category performance) using dynamic formulas and pivot tables.
* **Executive Reporting & Visualization:** Designed clear charts and structured an actionable executive brief highlighting key findings and strategic recommendations for operations management.

## Tools & Skills
* **Google Sheets / Microsoft Excel:** Data Cleaning, Pivot Tables, Logical & Lookup Formulas, KPI Modeling, Executive Dashboarding.
